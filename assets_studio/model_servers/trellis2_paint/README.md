# TRELLIS.2 Paint

`3d-paint`: готовая игровая сетка + исходная картинка с прозрачностью → GLB
с PBR-материалом. Генератор формы не загружается. Сетка не упрощается;
существующие UV сохраняются, при их отсутствии CuMesh делает развёртку.
После покраски можно запечь нормали из исходного Hi3D через `animation_tools`.

```sh
just setup
just download
just test
just serve                  # 127.0.0.1:9131
```

На RTX 3070 Laptop 8 GB проверена внутренняя сетка материала 512,
12 шагов, текстура 2048: около 3 GiB видеопамяти на сетке 80k.
Компоненты по фазам переходят между CPU и GPU; опубликованные fp16/bf16
веса используются без квантования. Для непрозрачного референса сначала
удалите фон через BiRefNet.

Исходники, веса и отдельное окружение лежат в `~/.cache/assets-studio/`:
`trellis2-source`, `trellis2-paint`, `venvs/trellis2_paint`.
Первый setup собирает FlexGEMM, CuMesh, o-voxel и nvdiffrast; готовые
колёса сохраняются в `trellis2-paint-native/wheels`. При установке o-voxel
не подтягиваются повторно его Git-зависимости. Сборка рассчитана на sm_86,
PyTorch 2.8/CUDA 12.9/Python 3.11.

Адаптер сохраняет масштаб и положение, UV и нормали входа. Проверяется
сохранение поверхности после развёртки. Единственный патч upstream:
копирование read-only `vertex_normals` перед преобразованием осей,
для совместимости с современным trimesh.

Источники: [TRELLIS.2](https://github.com/microsoft/TRELLIS.2),
[веса](https://huggingface.co/microsoft/TRELLIS.2-4B).
