# XTTS model server

Text-to-speech по контракту v1 на основе
[XTTS-v2](https://huggingface.co/coqui/XTTS-v2) (Coqui Public Model License,
некоммерческая) через поддерживаемый форк
[coqui-tts](https://github.com/idiap/coqui-ai-TTS).

```sh
just setup    # окружение Python 3.11 + PyTorch 2.5.1/CUDA 12.4 + coqui-tts
just doctor   # PyTorch, GPU, скачаны ли веса, совпадают ли встроенные голоса
just serve    # http://127.0.0.1:9103; веса (~2 ГБ) скачиваются при первом запуске
just test     # объявления, языки, разбиение текста, образцы голоса; без GPU
              # (скачивает только словарь токенизатора, ~0,4 МБ)
```

- 14 языков, по умолчанию русский; 58 встроенных голосов. Китайский,
  японский и хинди не объявлены: их обработке текста нужны пакеты, которых
  нет, а цифры на хинди coqui не произносит.
- Необязательный вход «Образец голоса» (WAV, 3–30 с чистой речи) клонирует
  голос; без него звучит выбранный встроенный голос.
- «Вариативность» — температура сэмплирования; «Скорость» — темп речи.
- Длинный текст (от ~180 символов для русского) делится на предложения
  (spaCy); предел — 5000 символов.
- Образец голоса: от 1 с до 5 мин, не тишина; голос задают первые 30 с
  (настройки клонирования — из конфигурации модели).
- Каждый вариант использует свой seed; одиночный запрос с этим seed
  повторяет вариант побитово.

Модель занимает ~2 ГБ видеопамяти, синтез — примерно в реальном времени
(~0,9×). Её можно держать запущенной вместе с моделью картинок или 3D.

`transformers` закреплён на 4.57.6: XTTS использует внутренние функции,
убранные в 5.x.
