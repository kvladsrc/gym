# Stable Audio model server

Звуки, эффекты и музыка по контракту v1 на основе
[Stable Audio Open 1.0](https://huggingface.co/stabilityai/stable-audio-open-1.0):
44,1 кГц, стерео, до 47 с.

```sh
just setup    # окружение Python 3.11 + PyTorch 2.5.1/CUDA 12.4 + diffusers
just doctor   # PyTorch, GPU, найден ли токен, скачаны ли веса
just serve    # http://127.0.0.1:9105; первый запуск скачивает ~5 ГБ
just test     # без GPU и весов
```

Веса закрыты на Hugging Face: аккаунт должен принять условия модели, а его
токен — быть в `HF_TOKEN` (или `HUGGINGFACE_TOKEN`) либо сохранён через
`hf auth login`. Лицензия — Stability AI Community License: некоммерческое
использование и малый бизнес.

## Задачи

- **text-to-audio** — звук по описанию: длительность 0,5–47 с, шаги,
  следование описанию, «чего избегать», выравнивание громкости.
- **audio-to-audio** — изменение звука (для эволюции): исходный WAV (моно
  или стерео, любая частота; учитываются первые 47 с), сила изменения и
  необязательное описание. Громкость результата — как у исходника.

Модель целиком на GPU (fp16). ~25 с на звук при 100 шагах, независимо от
длительности: модель всегда считает окно 47 с; четыре варианта по 47 с —
~100 с. Видеопамять: ~3,5 ГБ между запросами, пик во время генерации —
до 6,4 ГБ (с кешем аллокатора до 7,6 ГБ), тоже независимо от длительности.
Поэтому сервер лучше запускать одного.

## Что сделано поверх diffusers

- **Настоящий audio-to-audio.** `initial_audio_waveforms` в пайплайне
  складывает исходник с шумом полной силы (σ = 500): от исходника почти
  ничего не остаётся. Здесь исходник зашумляется до уровня, выбранного
  силой, и все шаги снимают шум с этого уровня (`schedule.py`).
- **Шкала силы.** Исходник сохраняется примерно до σ ≈ 1, наполовину
  меняется к σ ≈ 4–9, а с σ ≈ 23 (из 500) результат уже как новый звук.
  Поэтому сила отображается в σ логарифмически от 0,3 до 40: 0,1–0,3 —
  лёгкая правка, 0,5 — заметная, 0,7 — половина исходника, 0,9–1 — новый
  звук.
- **Громкость.** Громкость у модели гуляет от −40 до 0 дБFS, бывает
  клиппинг; по умолчанию пик выравнивается до −1 дБ (в audio-to-audio — до
  пика исходника), усиление — не больше +40 дБ (исходный пик — в
  `meta.peak_before_normalizing`).
- После каждого запроса кеш видеопамяти отдаётся обратно (иначе процесс
  держит ~7,6 ГБ и между запросами).

## Музыка

Модель обучена и на музыке (FMA): лупы, эмбиент, фоновая музыка до 47 с с
заданным темпом (`128 BPM` в описании соблюдается). Песни с голосом и
длинные треки — не её задача.
