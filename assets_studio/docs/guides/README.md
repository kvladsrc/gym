# Руководства: как делать ассеты студией

<!-- markdownlint-disable MD013 -->

Что сработало, а что нет, когда студией делали ассеты для целой игры:
персонажей с анимацией, окружение, уровень, голоса и музыку. Выводы
проверены на сотнях вариантов с оценками; числа — с ноутбучной RTX 3070
(8 ГБ). Правила не привязаны к жанру или проекту.

Коротко:

- **3D: Qwen-Image → Hunyuan3D-2mini → Hunyuan3D-Paint.** Ничто из
  опробованного (TripoSR, Stable Fast 3D, FLUX как источник) не приблизилось;
  даже из слабой картинки получается модель для игры.
- **Промпт — абзац о предмете как о вещи со строением**, не список слов;
  простой стиль с крупными пятнами цвета, матовый свет, один связный объект.
- **Не уменьшать модели вручную и не сваривать их «потом»:** сетки Paint
  разрезаны по швам UV; уменьшенные без сварки, они рвутся.
- **Персонажи: A-поза, руки пустые, ноги видны, без хвостов и плащей;**
  в движке — Generic, а не Humanoid; клипы — на месте.
- **Голос клонируется только с чистой речи;** ударения XTTS не задать.
