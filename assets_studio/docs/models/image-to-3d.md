## TripoSR — сервер удалён (октябрь 2026)

TripoSR и Stable Fast 3D удалены: цепочку Hunyuan3D-2mini → Paint ничто не
догнало (итог ниже). Замеры — для истории.

Проверено 29 сентября 2026 на RTX 3070 Laptop (8 ГБ).

| | |
| --- | --- |
| Лицензия | MIT (код и веса) |
| Ревизии | исходники `107cefdc`, веса `5b521936` |
| Загрузка модели | 53 с (веса из локального кеша) |
| Генерация | 6,4 с на картинку 1024×1024, `mc_resolution=256` |
| Видеопамять после генерации | ~3,2 ГБ (по `nvidia-smi`, справочно) |
| Результат для героя платформера | 32 298 вершин, 64 596 треугольников, замкнутая сетка, GLB 1,3 МБ — совпадает с прежним прогоном прототипа |
| Проверка контракта | 0 ошибок, 1 предупреждение |

Предупреждение — «результат не зависит от seed»: TripoSR — модель прямого
прохода, одинаковая картинка всегда даёт одинаковую сетку. Поэтому
`max_count = 1`, а варианты в 3D получаются через варианты входной
картинки. Проверка запускается с `--allow-seed-independent`.

Качество: силуэт и поза сохраняются, лицо, пальцы и фактура упрощены
(проверено ещё в прототипе платформера, ныне удалённом). Это быстрый
черновик формы.

## Итог сравнения (октябрь 2026)

Stable Fast 3D и Hunyuan3D-2mini (лицензия не действует в ЕС) добавлены и
сравнены с TripoSR на ~240 вариантах с оценками. Выбрана цепочка
**Qwen-Image → Hunyuan3D-2mini → Hunyuan3D-Paint**: ровные фигуры,
правдоподобные скрытые стороны, текстура по исходной картинке. Числа,
промпты и ограничения — в [руководстве](../guides/3d.md). TRELLIS не
проверен (вероятно, не помещается в 8 ГБ).

## Выводы для контракта

Контракт v1 изменений не потребовал. Долгая загрузка (53 с) корректно
видна как `loading`; base64 для GLB 1,3 МБ проблем не создаёт;
детерминированная модель выражается через `max_count = 1` и флаг проверки.
