## Iteration 1

Verdict: **REVISE**, two blockers and ten recommendations. The critic reviewed
code, screenshots and the live Studio in a browser.

### Iteration 1: blockers

1. **Sending results to a tab lost inputs** when switching tasks (image →
   “→ Images” opened image-to-image empty): two `TabPage` effects overwrote
   each other. *Fixed:* drafts moved to `state/drafts.ts`; `sendTo` is one
   action rather than chained effects. Browser test: input survives task
   changes within a tab.
2. **Decimal parameters could not be typed** (“0.25” became “250”) because
   fields were number-controlled. *Fixed:* retain typed text, committing a
   number only when valid and in range (including `exclusiveMinimum`). Otherwise
   highlight, show range and block submission. Tests: keystroke entry “0.25”
   and out-of-range input.
