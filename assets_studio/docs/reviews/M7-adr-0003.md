# Ревью: ADR-003 (контракт 1.1 — текст, видео, основные параметры)

Критик, 3 итерации, ACCEPT. Вместе с правкой Ctrl+C в студии.

## Итерация 1 — REVISE

1. Сигнатура MP4 принимала любой `ftyp`: голосовая заметка M4A, AVIF и
   HEIC попадали в библиотеку как видео; WebM без видеодорожки тоже.
2. Канонические форматы не соблюдались: текст с BOM/CRLF и MP4 в HEVC,
   10 бит, с `moov` в конце уходили серверам и в библиотеку как есть.
3. Слабые сигнатуры звука срабатывали раньше текста: текст «ID3 …» или
   «OggS …» считался звуком, а результат text-to-text, начинающийся так,
   проваливал задание.
4. Выбор файла в форме генерации предлагал только объявленный сервером
   WAV — новая загрузка FLAC/OGG/MP3 была спрятана.

Плюс уязвимость (рекомендация): ffmpeg подбирал демультиплексор по
содержимому — подделанный «MP3», импортированный по ссылке, мог дойти до
плейлиста и читать локальные файлы. Теперь `-f` по типу и
`-protocol_whitelist file`.

## Итерация 2 — REVISE

Проверка канонического видео не смотрела на звук: MP4 со звуком Opus или
FLAC считался каноническим. Теперь звук не AAC — повод перекодировать.

## Итерация 3 — ACCEPT

Принята рекомендация: при отправке хранимое видео проверяется только по
раскладке боксов, без ffprobe.

Отклонены (локальный инструмент, качество важнее): более быстрый пресет
при импорте, сброс HDR-тегов цвета, ограничение размера текста в
просмотре, `aria-describedby` у подсказок полей.
