# Review: ADR-003 (contract 1.1 — text, video, primary parameters)

Critic: three iterations, ACCEPT. Includes Studio Ctrl+C fix.

## Iteration 1 — REVISE

1. MP4 signature accepted any `ftyp`: M4A voice notes, AVIF and HEIC became
   library videos, as did WebM without video tracks.
2. Canonical formats were not enforced: BOM/CRLF text and HEVC, 10-bit,
   trailing-`moov` MP4 were stored/sent unchanged.
3. Weak audio signatures ran before text: “ID3 …” or “OggS …” text was treated
   as audio, failing similarly prefixed text-to-text results.
4. Generation pickers offered only server-declared WAV, hiding newly imported
   FLAC/OGG/MP3.

Additional vulnerability recommendation: content-selected ffmpeg demuxers
could interpret a URL-imported fake MP3 as a playlist and read local files.
Now uses explicit type-based `-f` and `-protocol_whitelist file`.

## Iteration 2 — REVISE

Canonical-video checks ignored audio: Opus/FLAC MP4s were considered canonical.
Non-AAC audio now triggers transcoding.

## Iteration 3 — ACCEPT

Accepted: validate stored video at dispatch by box layout only, without ffprobe.

Rejected (local tool, quality prioritized): faster import preset, stripping HDR
color tags, text-preview size limits, `aria-describedby` on parameter hints.
