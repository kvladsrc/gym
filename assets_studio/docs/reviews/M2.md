## Iteration 1

Verdict: **REVISE**, one blocker and nine recommendations.

### Iteration 1: blocker

1. **Ctrl+C failed to stop Studio with an open event stream or long job wait.**
   The web UI keeps a stream open permanently, making Studio impossible to stop.
   *Fixed:* uvicorn `timeout_graceful_shutdown`; Studio shutdown wakes all
   waiters (`Studio.closing`) and ends streams. SIGINT test with both open:
   exit under ten seconds.

### Iteration 1: recommendations

| # | Finding | Resolution |
| --- | --- | --- |
| 1 | REST lacked Host validation; DNS rebinding exposed API to web pages | `TrustedHostMiddleware`: localhost and bind address only. Test |
| 2 | SSE subscription outside generator leaked on quick disconnect; unbounded queue | Subscribe inside generator; set of IDs coalesces same-job events |
| 3 | SSE blocked event loop | Read tabs/jobs in thread pool |
| 4 | Waiting occupies a worker for up to 600 s | Unchanged: one user/few agents cannot exhaust limit; shutdown wakes waiters |
| 5 | MCP `"id:index"` differed from REST and caused parsing errors; wait lacked paths; 300 s timeout | `input_jobs` uses `{job_id, output_index}` as REST; return `output_paths`; 60 s timeout with call-again hint |
| 6 | `import_asset` read entire file before size check | `stat()` and limit first |
| 7 | Missing files caused 500; downloads named by hash | 410; readable `Content-Disposition` name. Test |
| 8 | Two error shapes: string/list `detail` | Always string. Test |
| 9 | `POST /mcp` without slash redirected | Serve exactly `/mcp` |
