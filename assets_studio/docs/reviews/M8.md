# Review: M8 — output sections, model selection, asset deletion and CI

Critic: two iterations, ACCEPT (ADR-004).

## Iteration 1 — REVISE

1. Outputs needed by waiting dependency jobs could be deleted (only direct
   inputs checked). Downstream jobs failed file-not-found, or silently used
   deleted assets sharing a blob. Also a validation/insertion race.
2. Build-node `python311` shadowed `python314`'s `python3` (first wins in
   `symlinkJoin`), which would run all CI jobs on 3.11. The image now exposes
   only `python3.11` for that version.
3. Old dispatcher bug: every poll reset the worker-thread reference, so
   `stop()` did not join workers and Studio could close the database while
   they still wrote to it.

Recommendations accepted: clear `[[tabs]]` configuration error; corrupt server
records do not block startup; MCP omits deleted file paths; model replacement
on a port does not hide historical jobs; selected models are remembered only
on click and survive task changes.

## Iteration 2 — ACCEPT

Follow-up: configured parameters freeze automatic model selection (another
model becoming ready would otherwise reset them); counts/inputs always adapt
to the selected model; jobs depending on deleted results reject immediately
(422), not later in the queue.

Left unchanged: PATCH of deleted assets, 409 rather than 422 for retries with
deleted inputs, rejection of waiting jobs for servers absent from configuration.
