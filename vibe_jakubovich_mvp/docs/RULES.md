# Правила MVP

У телешоу менялись сектора, номиналы и суперигра. Здесь выбрана классическая
схема: три отборочные тройки → три победителя в финале → покупка призов
за очки → добровольная суперигра с одним словом. Это вариант ранних
выпусков, не полная копия действующего регламента 2026 года.

Источники для сверки:
[описание шоу](https://www.vokrug.tv/product/show/pole_chudes/),
[история правил и секторов](https://gameshows.ru/wiki/ПЧ),
[сводное описание](https://ru.wikipedia.org/wiki/Поле_чудес).
Передача имеет исторические варианты и решения ведущего;
точные игровые договорённости перечислены ниже.

## Основной раунд

Три участника по очереди вращают барабан. Числовой сектор даёт очки
за каждое вхождение правильно названной буквы. Все вхождения открываются,
и игрок сохраняет ход. Буква отсутствует — ход переходит дальше.
Повторно названная буква отклоняется без изменения состояния.
Ё и Е считаются одной буквой; гласные не покупаются.

В свой ход можно назвать слово целиком. Неверное слово исключает игрока
из текущего раунда; правильное определяет победителя. Открытие последней
буквы также автоматически завершает раунд. Если все игроки выбыли,
раунд заканчивается без победителя.

| Сектор | Действие |
| --- | --- |
| Число | Номинал × число вхождений буквы |
| Банкрот | Обнулить очки, передать ход |
| Ноль | Сохранить очки, передать ход |
| Плюс | Выбрать клетку, открыть все вхождения её буквы |
| Приз | Взять подарок и выйти либо назвать букву за 1000 очков |
| ×2 | При верной букве умножить счёт на число вхождений + 1 |

Номиналы и расположение 16 секторов заданы в `RoundRules.SECTORS`.
Каждый сектор равновероятен. Итог выбирается до анимации, и барабан
точно останавливается на соответствующем секторе.

Три подряд самостоятельно угаданные буквы дают две шкатулки:
одна пуста, другая содержит 5000 ₽. Деньги не сгорают при банкротстве
и проигрыше суперигры. «Плюс» и передача хода сбрасывают серию.
Автоматическое открытие по «Плюсу» не приносит очков.

## Турнир

Человек играет в первой тройке. Две другие отборочные тройки полностью
разыгрываются ботами без показа анимаций; результаты видны перед финалом.
Все три победителя сохраняют набранные очки. При банкротстве сгорает
весь текущий счёт, но не деньги из шкатулок.

Боты не получают скрытый ответ: используют частотность ещё не названных
букв и позиции закрытых клеток. Они отказываются от сектора «Приз»,
не пытаются назвать слово целиком и побеждают открытием последней буквы.
Вопросы не повторяются внутри выпуска, но могут повториться в новом.

Победитель финала выбирает по одному призу каждого вида, пока хватает
очков: чайный сервиз, велосипед, телевизор. Эти предметы и их стоимость
— фиксированная игровая витрина, не исторические цены конкретного выпуска.

## Суперигра

Участник может сохранить призы и закончить игру. При согласии на риск
получает новый вопрос, выбирает три разные буквы, затем все их вхождения
открываются. После выбора третьей буквы запускается таймер на 60 секунд.
Одна попытка назвать слово; неверный ответ или истечение времени — проигрыш.
Окно ввода не останавливает таймер. Явная пауза останавливает его.

Победа добавляет автомобиль. Проигрыш лишает призов, купленных за очки,
но сохраняет деньги из шкатулок. Автомобиль здесь фиксированный суперприз.
Современный вариант с тремя пересекающимися словами, исторические сектора
«Шанс», «Ключ», «Миллион», торг ведущего и музыкальные номера вне MVP.
